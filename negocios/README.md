# Respaldo público de negocios

Esta carpeta contiene una copia pública y sanitizada de los sitios de `negocios`.

Incluye recursos visuales y datos públicos:

- HTML, CSS y JavaScript del cliente.
- Imágenes, iconos, fuentes y PDFs públicos.
- JSON de contenido que no contiene credenciales.

Se excluyeron deliberadamente:

- Archivos PHP del servidor.
- Archivos SQL.
- Carpetas `admin`.
- Scripts de sincronización.
- Archivos `.env`, configuraciones privadas y secretos.

No publicar contraseñas, tokens, claves API, credenciales MySQL, sesiones ni archivos de OAuth en GitHub.
